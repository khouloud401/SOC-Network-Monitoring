🛡️ SOC — Surveillance Réseau d'Entreprise
> 🔧 Work in Progress
Projet académique de mise en place d'un SOC (Security Operations Center) complet pour la surveillance et la détection des menaces dans un réseau d'entreprise simulé.
---
## 🎯 Objectifs
- Concevoir une architecture réseau sécurisée
- Détecter les intrusions en temps réel
- Centraliser et analyser les logs
- Simuler des attaques pour tester la détection

## 🛠️ Outils utilisés

| Outil | Rôle |
|-------|------|
| pfSense | Firewall / Routage / VLANs / DMZ |
| Suricata | IDS/IPS — Détection d'intrusions |
| Wazuh | SIEM — Collecte et analyse de logs |
| Kali Linux | Machine attaquante — simulation d'attaques |
| Windows Server | Machine cible |
---
✅ Fait
 -  Conception de l'architecture réseau (DMZ, VLANs)
 -  Configuration du firewall pfSense
 -  Déploiement de Suricata IDS/IPS
 -  Déploiement du SIEM Wazuh
 - Collecte des logs et génération d'alertes
 - Simulation d'attaques réseau (scan Nmap, brute force)
 ---
🔧 En cours
 - Optimisation des règles de détection Suricata

 - Documentation complète des scénarios d'attaque
